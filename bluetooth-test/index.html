Ruuvi · Bluetooth-Test

Worum es geht

Diese Seite prüft, ob das Tablet die Temperatursensoren selbst auslesen kann – so wie der Raspberry Pi nach der Rückkehr. Sie liest nur und speichert nichts: Die Werte bleiben auf dieser Seite und sind beim Schließen weg. Nichts geht an Supabase.

Voraussetzungen

Auf dem Tablet: Bluetooth und Standort einschalten, die Seite in Chrome öffnen. Beim ersten Mal fragt Chrome nach „Geräte in der Nähe“ – erlauben.

Zeitraum

Gemerkte Sensoren

Chrome hat sich Sensoren aus einem früheren Test gemerkt. Damit kann die App später ohne Auswahlfenster auslesen.

So testen

  1. Unten auf „Sensor suchen und auslesen“ tippen und im Fenster einen Sensor („Ruuvi …“) wählen.
  2. Warten, bis die Karte grün wird. Für einen zweiten Sensor einfach nochmal tippen.
  3. „Nochmal auslesen“ testen – das sollte ohne Auswahlfenster gehen.
  4. Seite neu laden: Steht oben „Gemerkte Sensoren“? Dann merkt sich Chrome die Sensoren.
  5. Am Ende „Protokoll kopieren“ und mir schicken.

In der Firma kann der Pi gerade mit einem Sensor verbunden sein – dann schlägt das Auslesen fehl. Einfach nach einer Minute nochmal versuchen. Dem Pi schadet der Test nicht: Er holt fehlende Werte selbst nach.
